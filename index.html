FAQ

Частые вопросы

Коротко о главном — перед тем как скачать.

Это бесплатно?
Абсолютно бесплатно. Версия Free работает без ограничений по времени — без регистрации, без подписок и без скрытых платежей. Pro-функции опциональны и покупаются один раз, только если захотите.
Это безопасно?
Да. Установочный скрипт открыт на GitHub — его можно прочитать перед запуском. Всё скачивается и работает локально, никакие данные никуда не отправляются.
Нужен ли интернет?
Только во время установки — чтобы скачать скрипт и модель. Дальше MIWOO работает полностью офлайн.
Антивирус блокирует установку. Что делать?
Windows SmartScreen может предупредить — это нормально для скриптов из интернета. Нажмите «Подробнее» → «Выполнить в любом случае». Содержимое скрипта открыто, можно проверить вручную.
Потянет ли мой компьютер?
Да. Достаточно 8 ГБ RAM и любой WebGPU-совместимой графики — даже встроенной Intel или AMD. Для слабых ПК используется модель 3B, для мощных — 7B Pro.
Где хранятся мои данные?
Только на вашем диске. Чаты, файлы и настройки не покидают устройство. Никакого облака, аналитики и телеметрии.

Установка MIWOO

Установка выполняется одной командой в PowerShell. Скрипт сам скачает и настроит всё необходимое — это займёт меньше минуты.

1
Откройте PowerShell от администратора
Нажмите Win + X и выберите «Терминал (администратор)» или «Windows PowerShell (администратор)».
2
Вставьте команду и нажмите Enter
Скопируйте команду ниже — она загрузит официальный установщик MIWOO напрямую из GitHub.
3
Дождитесь завершения установки
Через ~1 минуту ярлык MIWOO появится на рабочем столе. Первый запуск может занять чуть больше времени — загружается модель.

Системные требования

MIWOO работает на любом современном ПК. Модель ИИ загружается один раз и работает офлайн — без интернета.

Операционная система
Windows 10 или Windows 11 (64-bit). Сборка 1903 или новее.
Процессор
Любой x64 процессор. Intel Core i3 / AMD Ryzen 3 и выше.
Оперативная память
8 ГБ минимум · 16 ГБ рекомендуется для модели Pro 7B.
Графика
Любая WebGPU-совместимая. Встроенная Intel / AMD тоже подойдёт.
Место на диске
5 ГБ для установки и моделей. Кэш хранится локально.
Интернет
Нужен только при установке. Дальше — полностью офлайн.
Если у вас 6 ГБ RAM или встроенная графика — MIWOO работает, но модель 3B рекомендуется вместо 7B Pro. Обе версии совместимы с одинаковыми требованиями.
